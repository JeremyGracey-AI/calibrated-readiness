# ECA-200 Study Resources by Domain

*Synthetic knowledge document for the Calibrated Readiness Foundry IQ knowledge base.*

Curated resources the Study Plan agent draws from. Each entry lists an estimated
focused-study time so plans can be fit to a learner's available weekly hours.

## D1. Identity & Access (20%)
- "Entra ID Fundamentals" microcourse - 3h
- Hands-on lab: conditional access policies - 2h
- RBAC vs ABAC decision guide (reading) - 1h

## D2. Networking (22%)
- "Hub-and-spoke VNet design" workshop - 4h
- Private endpoint + hybrid DNS lab - 3h
- Load balancing decision tree (reading) - 1h

## D3. Data & Storage (18%)
- "Choosing a data store" scenario set - 3h
- Storage replication & tiering lab - 2h
- Encryption at rest / key management reading - 1h

## D4. Reliability & Ops (25%) - highest weight, prioritize
- "Designing for SLOs" workshop - 4h
- Autoscaling + backup/restore lab - 3h
- Observability & incident response scenario set - 3h
- Postmortem case studies (reading) - 2h

## D5. Security & Governance (15%)
- Policy-as-code lab (Bicep/Terraform guardrails) - 3h
- Threat detection & compliance baseline reading - 2h

## Sequencing guidance
Start with the learner's weakest *high-weight* domain (usually D4), not their
weakest domain overall. A 10-point gain in a 25%-weight domain moves the score
more than the same gain in a 15%-weight domain.
